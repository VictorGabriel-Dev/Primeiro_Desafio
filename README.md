# Primeiro_Desafio
Projeto desenvolvido como avaliação prática da trilha "Formação HTML Web Developer" na plataforma DIO. 

🚀 Conteúdo Abordado

A página está organizada para explicar os seguintes tópicos:

1. Arquitetura Client-Server

O que são Clients? - Uma breve explicação sobre os dispositivos que fazem requisições.

O que são Servers? - O papel dos servidores em armazenar e entregar recursos.

Grandes Nomes - Um reconhecimento a pioneiros da computação e da internet, como:

Alan Turing

Ada Lovelace

Vint Cerf

Bob Kahn

Tim Berners-Lee

2. Introdução ao HTML na Prática

Estrutura Básica - Como o HTML é organizado.

Tags Fundamentais - Explicação de tags essenciais usadas no documento, como:

<p> (Parágrafo)

<h1> a <h6> (Títulos)

<ul> (Lista não ordenada)

<ol> (Lista ordenada)

<li> (Item da lista)

Atributos das Tags - O que são e para que servem atributos comuns:

id

class

style

title

lang

Listas Ordenadas e Não Ordenadas - Como criar listas em HTML.

Links (Âncoras) - Como usar a tag <a> com o atributo href para criar links internos e externos.

🛠️ Como Visualizar

Clone ou baixe este repositório.

Certifique-se de que o arquivo index.html e a pasta Exemplos/ (contendo as imagens) estejam no mesmo diretório.

Abra o arquivo index.html em qualquer navegador web (como Chrome, Firefox, Edge, etc.).
